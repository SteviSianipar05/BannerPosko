# BannerPosko
Sistem Pengelolaan Banner Berbasis Web ini merupakan aplikasi pendukung layanan posko utama Bandara Soekarno-Hatta untuk menampilkan digital signage tentang fungsi posko di hari besar. Tujuan penerapan sistem ini adalah untuk mengakomodasi segala urgensi posko utama tersebut,menjamin efektifitas,efisiensi monitoring sistem banner di posko utama.
